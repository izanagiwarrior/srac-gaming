## Human portrait expansion (released in3.5.0)

Six individual portraits generated with the built-in imagegen tool on31October2026. All fictional adults, not user photos. Original PNGs retained outside the repo; project copies scaled to384×384PNG using sips for web delivery. All six catalog prices are0coins; free claim uses the same server-owned inventory/equipment flow. No runtime generator, API key or schema change. Studio and game badges resolve catalog-approved images.

Generate one original square game profile avatar asset. {subject}. Premium stylized hand-painted 3D clay character portrait, welcoming cozy board-game social club aesthetic. Head and shoulders centered, face large occupying about 55% of square, entire hair/head safely inside centered 80% circle, gently rounded forms, subtle tactile clay material, appealing expressive eyes, refined soft studio lighting. Dark forest-green circular vignette background with muted teal halo, warm cream and gold accents, simple quiet composition. Readable as a tiny 40px circular avatar. Fully illustrated fictional adult, not a real person, not a photo. Exactly one person, no playing cards, no hands in foreground, no text, no letters, no logos, no watermark, no border, no collage. Individual avatar name for internal reference only: {id}.
