# Player titles

Candidate3.12.0 supersedes3.11.22 with English titles and rank cosmetics. The shared definition remains public/player-titles.js. See [rank rewards, ownership, profile configuration and actual verification limits](RANK-COSMETICS.md).

| Level | Title | Starting XP |
|---|---|---|
|1–4|Initiate|0|
|5–9|Silver Vanguard|1600|
|10–14|Jade Sentinel|8100|
|15–19|Golden Sovereign|19600|
|20–29|Astral Legend|36100|
|30+|Celestial Dragon|84100|

Titles derive from the existing server level; they grant no administrative privilege. Spending coins never reduces XP. Global/profile uses lifetime account XP; per-game leaderboard uses that game's existing level/XP. Profile shield, next title and collapsed roadmap share the definition with leaderboard and compact profile accessible labels. No new request/polling is added for title display.
